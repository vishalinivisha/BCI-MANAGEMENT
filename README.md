# BCI-MANAGEMENT
The project was modified to demonstrate:
1. Abstract class - Employee in employee.py
2. Abstract method - calculate_salary() in Employee
3. Method overloading - Student.addCourse() using an optional semester argument
4. Method overriding - calculate_salary() and show_sal() in AcademicEmployee and NonAcademicEmployee
5. Static method - Course.is_valid_credit() in course.py
6. Non-static methods - display_course(), show_sal(), calculate_gpa(), etc.

How to run:
- python findavg.py       -> Student GPA and average
- python salary.py        -> Employee salary details
- python oop_concepts_demo.py -> Demonstrates all six OOP concepts
